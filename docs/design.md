# Review desk

The application serves an internal bid reviewer. The main object is the requirement, with the original source beside it.

- Ink: #172e46. Paper: #ffffff. Workspace: #edf2f6. Action: #185d91. Blocker: #a53730. Confirmed: #21674a.
- System sans-serif for controls and data. Georgia for proposal text only.
- Left: bids and company files. Center: requirement review. Right: source and evidence, opened on demand.
- Use a compact table for comparison. Use a document page for the draft.
- Show actual blockers and the next action. Do not show a readiness score that can hide a blocker.
- Keep keyboard focus visible. Stack columns on small screens. Do not use decorative motion.

The main screen is a work surface, not a landing page. The requirement ledger carries the visual emphasis.
