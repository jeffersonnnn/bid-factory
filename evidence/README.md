# Verification evidence

This folder contains review evidence for the handover.

## Records

- `verification.md` records the observed V0 checks and limits.
- `current-test-results.txt` records the latest automated test run.
- `secret-scan.txt` records the final repository scan without secret values.
- `rendered-checks` contains selected fictional output images used during visual review.

These records use synthetic fixtures. They do not approve a real contractor or government submission.

Do not add customer source files, credentials, local databases, or live proposal packages to this repository.
