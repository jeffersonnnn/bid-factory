# Operations handover

Use this folder with the main [handover status](../HANDOVER_STATUS.md).

## Start in this order

1. Read `handover/Bid-Factory-Operator-Handover-Primer.docx`.
2. Read `access-and-accounts.md`.
3. Complete `decision-rights.md` with Jefferson.
4. Review and sign `contractor-agreement-template.md` after local legal review.
5. Use the files in `launch-kit` to sell and deliver the first pilot.
6. Review the records in `../evidence` before changing product controls.

## Folder contents

- `handover` contains the operator primer.
- `launch-kit` contains the offer, funnel, scripts, forms, reviewer kit, and sample.
- `access-and-accounts.md` contains the account handoff plan.
- `decision-rights.md` defines who can make each decision.
- `contractor-agreement-template.md` is a working legal template.

Do not store keys, passwords, customer files, or payment details in this repository.
